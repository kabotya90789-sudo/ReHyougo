# ReHyogoMst

## 概要
これは職業訓練校「Java + Pythonプログラマー養成コース」のチーム課題で制作した、Java製の観光Webアプリケーションです。  
Servlet / JSP を用いたMVC構成で開発しました。.SQLフォルダ内のインポート文からデータベースを作成してから起動してください。

## 開発環境
- Eclipse
- Apache Tomcat 10
- A5:SQL Mk-2
- MySQL
- JavaSE-21

## 使用技術
- Java
- Servlet / JSP
- HTML / CSS / JavaScript
- MySQL
- JDBC
- Jackson
- Apache Commons Codec
- Git / GitHub

## Eclipse設定情報
このプロジェクトは Eclipse Dynamic Web Project 構成で作成しています。

### 主な設定
- Java : 21
- Tomcat : 10
- Servlet Version : 6.0
- Dynamic Web Project

## ライブラリ
使用ライブラリ：
- mysql-connector-j-9.5.0
- jackson-core-2.21.2
- jackson-databind-2.21.2
- jackson-annotations-2.21
